# IGPS Structural Data

This repository contains selected structural files associated with the study:

**Time Evolution of the Millisecond Allosteric Activation of Imidazole Glycerol Phosphate Synthase**  
Carla Calvó-Tusell, Miguel A. Maria-Solano, Sílvia Osuna, and Ferran Feixas  
*Journal of the American Chemical Society*, 2022, 144, 7146–7159.  
[Read the article](https://pubs.acs.org/doi/full/10.1021/jacs.1c12629)

## About

Imidazole glycerol phosphate synthase (IGPS) is a model bienzyme complex for studying long-range allosteric regulation. In this work, molecular dynamics simulations, enhanced sampling, and dynamical network analysis were used to describe the millisecond allosteric activation pathway of IGPS.

This repository provides representative structures and trajectories from the study, including active, inactive, and intermediate conformational states.

## Repository contents

- `*.pdb` — representative IGPS structures
- `*.dcd` — molecular dynamics trajectory files
